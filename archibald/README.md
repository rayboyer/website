# Archibald's Adventure

A side-scrolling runner starring Archie the cat. Static files only, ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder (keep the `assets` and `js` folders).
2. In the repository, open Settings, then Pages, and choose "Deploy from a branch" with your main branch and the root folder.
3. Open the address GitHub shows you, for example `https://<your-name>.github.io/<repo>/`.

## Controls
Tap (or Space / Up) to jump, tap again while in the air for a high jump.
Hold the DUCK button (or Down / S) to crawl; on furniture it drops you to the floor.

## Files
- `index.html` – page shell
- `js/game.js` – game code; `js/sprites.js` – sprite rectangles
- `assets/archie-sprite-sheet.svg` – Archie (160x120 cells, 10 columns)
- `assets/props.svg` – furniture, plants, bath, alligators, doors
- `assets/bg-*.svg` – room and park backgrounds
